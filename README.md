# Saya no Uta Android Port

An unofficial Android port for Saya no Uta.

This project aims to make the game playable on Android devices with touchscreen controls, proper screen scaling, save support, and Android-compatible audio

This project is not affiliated with or endorsed by Nitroplus or the original copyright holders.

## Requirements
- Android 5.0 Lollipop or newer
- ARM64-compatible processor
- 2 GB RAM
- 1 GB of free storage
